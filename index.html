达人合作
项目介绍隐私政策使用条款

自托管的多 Gmail 邮件工具

把合作邮件，
放在一处处理。

连接自己管理的邮箱，发送合作邮件、查看关联回复，并用自有测试邮箱核验收件情况。

了解功能

围绕一次合作，整理邮件往来。

连接自己的账号

集中管理多个 Gmail 账号。通过 Google 授权连接邮箱，并按实际需要开启相应功能。

发送合作邮件

选择 Gmail API 或 SMTP 发送方式，使用已授权或已配置凭据的账号发送邮件。

查看关联回复

从已授权的发件 Gmail 账号读取相关回信，便于继续跟进合作沟通。

核验测试收件

仅检查自己拥有并授权的测试邮箱，记录邮件实际进入的位置。其他收件人的进箱情况不在检查范围内。

由使用者自行部署和管理。

达人合作面向个人或团队内部的合作邮件管理，由部署者负责运行环境、邮箱授权和数据保存。本项目介绍站提供功能与政策说明，无需登录。

本项目不提供付费订阅或收费邮件托管服务。使用前，请阅读数据处理范围和使用要求。
